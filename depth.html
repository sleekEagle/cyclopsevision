01 — Depth camera & SDK

Metric depth from a single lens.

Stereo rigs need two cameras and careful calibration. Active sensors need emitters and struggle outdoors. Our approach uses one camera with optics designed to make defocus blur informative, then applies learned models that read depth from that blur.

How it works

Defocus encodes distance

Light from a point at the focus distance lands on a single spot on the sensor. Light from a point at any other distance spreads into a disc called the circle of confusion. The disc's size follows directly from the point's distance.

Optics designed for the cue

Aperture and focus settings chosen so blur changes strongly and measurably across the working range.

Learned defocus models

Networks trained to separate blur caused by depth from blur that is already in the scene's texture.

Calibrated, metric output

The model knows the lens parameters, so it returns depth in meters, not just relative ordering.

The camera In development

Optics built for the cue

One sensor

No stereo baseline and no inter-camera calibration. The hardware is smaller and simpler.

Passive

No projector or laser, so it works in sunlight and doesn't interfere with other sensors.

Physically grounded

Depth comes from measured optics, not just learned scene priors, so it holds up on unfamiliar scenes.

Edge-ready

Designed to run on-device next to the camera, as well as on a workstation.

Standard formats

Export depth maps, point clouds and confidence maps.

depth_quickstart.py · API preview
import cyclopse

# Connect to the camera (or load images from disk)
cam = cyclopse.Camera.connect()
frame = cam.capture()

# Estimate metric depth from defocus
model = cyclopse.depth.load("dfd-base")
result = model.predict(frame)

result.depth        # H×W array, meters
result.confidence   # H×W array, 0–1

# Export
result.save("scene_depth.exr")
result.to_pointcloud().save("scene.ply")
